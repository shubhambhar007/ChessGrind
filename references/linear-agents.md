# Reference analysis

## Overall feel

Quiet confidence. The film keeps a near-black field, lets one real interaction own each shot, and avoids decorative motion that competes with the product.

## Composition and typography

- A single centered product phrase establishes context before UI arrives.
- Product UI is enlarged and cropped intentionally; the important row or menu owns the frame.
- White type is restrained and functional, with no multi-color headline treatment.
- Empty black space is used as pacing, not filled with particles.

## Motion grammar visible in sampled frames

- UI states replace one another through focused push-ins and clean cuts.
- Menus and panels stay spatially anchored while a selected row changes state.
- The cursor is subordinate to the interface and appears only when it explains causality.
- The ending clears back to a simple logo field.

## What ChessGrind adopts

- Dark, focused product framing.
- One decisive interaction per shot.
- Strong shared-element continuity from board selection to memory card.
- Confident holds after motion settles.
- Simple logo close.

## What ChessGrind does not copy

- Linear's purple accent, interface identity, layout, copy, or logo treatment.
- Audio or cut-sync claims: this analysis is based on sampled frames, not human playback of the reference soundtrack.
